# 🐾 Plataforma de Adoção de Animais

Uma solução moderna criada em hackathon para conectar animais resgatados a novos lares de forma rápida, simples e impactante.

---

## 🚀 O que é

Uma plataforma web onde usuários podem:

* Encontrar animais disponíveis para adoção
* Registrar resgates
* Contribuir com ONGs

Tudo em uma interface leve, responsiva e intuitiva.

---

## 🛠️ Tecnologias

* HTML
* CSS
* JavaScript
